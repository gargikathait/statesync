# StateSync design system

Status: **implemented (Milestone 1)**. Source of truth: `packages/design-tokens/src/palette.ts`.
`packages/design-tokens/tokens.css` is generated from it (`npm run tokens:build`); CI and a unit test fail if it is stale.
A live reference with computed contrast tables is served at `/design`.

## Brand palette

| Colour | Hex | Role |
|---|---|---|
| Ivory | `#F3F1EC` | Canvas / main background (light) |
| Moss | `#B6B8AB` | Brand accent: selection indicators, accent buttons, highlights |
| Smoke | `#9FA3AD` | Decorative and secondary: charts, icons on strong surfaces, dark-theme boundaries |
| Garden | `#E0DFD2` | Panels and grouped surfaces (light) |
| Midnight | `#3C3E4A` | Text, primary actions, navigation; raised surface in dark theme |

## Contrast corrections (why derived tokens exist)

Measured with WCAG 2.x relative luminance (`src/contrast.ts`, unit-tested against reference values):

- Midnight on Ivory **9.40:1**, on Garden **7.91:1**, on Moss **5.27:1**: safe for text.
- Midnight on Smoke is **4.20:1**: below AA for body text. Smoke is never used for small text with Midnight.
- Smoke on Ivory is **2.24:1** and Moss on Ivory is **1.78:1**: they fail even the 3:1 bar for UI boundaries.

Consequences, enforced by tests:

1. **Muted text** uses derived `muted` (`#5A5C68` light, `#BDBFC7` dark), not Smoke.
2. **Accent text** on light surfaces uses derived `accent-ink` (`#565A47`), not Moss.
3. **Input and control boundaries** use `line-strong` (`#6A6D78` light, Smoke in dark), never Moss or Smoke on light.
4. **Selection** is never signalled by Moss alone: Moss fills carry Midnight text and a Midnight or `accent-ink` indicator.
5. **White text is never placed on Moss, Smoke or Garden.**
6. **Semantic states** (success, warning, error, info) have separate `-bg`, `-fg` and `-icon` tokens in each theme, and state is always also conveyed by a text label and icon shape.

## Themes

- Light: Ivory canvas, Garden surfaces, Midnight ink, Moss accent.
- Dark: derived neutrals (`#25262E` canvas, `#2F303A` surface, `#1C1D23` strong) with Midnight as the raised surface, Ivory ink, Moss remaining the accent. It is not an inversion of the light theme.
- Selection: `<html data-theme="light|dark">` forces a theme; no attribute follows the OS (`prefers-color-scheme`). A tiny inline script applies a saved choice before first paint. Only the preference is stored in `localStorage`, never working state.
- Tailwind default colours are removed (`--color-*: initial`), so product colours can only come from these tokens.

## Typography, spacing, shape

- Display: editorial serif stack (Iowan Old Style / Palatino / Georgia). UI: system sans. Mono for URLs and versions. System stacks only: no webfont download, no layout shift, works offline. A bundled webfont can be added later.
- Spacing: Tailwind 4px base. Radii: 6px controls, 10px panels. 1px hairline borders; no heavy shadows.
- Focus: 2px outline in `focus` (Midnight light, Moss dark), 2px offset, on every interactive element. Reduced-motion and forced-colours media queries are handled in `globals.css`.

## Components (apps/web/src/components/ui)

| Component | Notes |
|---|---|
| Button, buttonClasses | primary, accent, secondary, ghost; sm and md; min target 32/40px |
| Panel | surface, raised, strong |
| StatusPill | The six sync states: synced, syncing, offline, pending, conflict, recovery. Label plus distinct icon shape |
| Callout | info, success, warning, error. `role="alert"` for errors, `role="status"` otherwise |
| TextField | Label, hint, error; `aria-describedby`, `aria-invalid` |
| TabStrip | Browser-style captured-tab representation (pinned, active, muted); read-only |
| ThemeToggle | Native radio group (Light / System / Dark), keyboard operable |
